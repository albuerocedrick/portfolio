# Goal

Establish a clear visual hierarchy that guides user attention toward primary content and actions.

# Instructions

## Typography

- Use only 3–4 typography sizes per screen.
- Create hierarchy primarily through font weight and spacing.
- Reserve the largest typography for page titles and critical content.

## Actions

- Each screen should have exactly one prominent primary action.
- Style primary actions using filled buttons.
- Style secondary actions using outline, ghost, or subtle variants.

## Content Organization

- Group related elements closely together.
- Separate unrelated sections using whitespace.
- Maintain consistent spacing throughout the interface.

## Readability

- Limit text line length to approximately 60–75 characters.
- Use at least 150% line height for body text.
- Structure content with clear headings and sections.

## Contrast

- Ensure critical content has strong contrast against its background.
- De-emphasize metadata and secondary information.
- Avoid low-contrast text for important actions.

# Constraints

- Do not create multiple competing primary actions.
- Do not rely solely on font size to establish hierarchy.
- Do not overcrowd screens with content.
- Do not use low-contrast colors for important information.
- Do not place unrelated elements too close together.

# Examples

## Input

Create a pricing page.

## Output

- Large page heading.
- Clear pricing cards.
- One highlighted primary CTA.
- Secondary actions styled as ghost buttons.
- Readable text width and spacing.
